## 1. 시나리오로 문제를 표현한다.

- 하나의 문제는 하나의 시나리오로 표현된다.
- 현재는 존재하지 않는 코드를 작성하며, IDE의 생성/리팩토링 기능을 활용하여 뼈대를 만든다.

## 2. 입출력 형식을 정의한다.

- 입력 문자열에서 어떤 형식의 정보를 추출해야 하는가?
- 화면 출력에 필요한 형식의 정보는 무엇인가?

## 3. 문제를 가장 단순하게 해결할 수 있는 방법을 생각한다.

- **가장 행복한 상황**부터 상상한다.
- 주석으로 고수준 문맥을 코드에 적는다.
- 확신이 없는 부분부터 테스트한다.

## 4. 요구사항 문서를 읽어보고 점검한다.

- 요구사항을 놓쳤을 가능성을 염두에 둔다.
- 테스트로 적절히 표현되었는지 기록해두고 참고하자.
